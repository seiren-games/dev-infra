# Rust警告対応ポリシー

## 基本方針
- Rustツールチェインが出力する警告はすべて対象とする（`cargo build`/`cargo clippy` など）。
- 警告は原因を取り除く形で修正する。
- 一時的な回避ではなく、Rustのイディオムに沿った実装へ直す。
- `#[allow]`の使用は禁止する。
- 警告対応のために`unsafe`を導入してはならない。

## 対応手順
1. 警告内容を理解し、原因箇所を特定する。
2. コードを修正して警告の根本原因を解消する。
3. 再度チェックを実行し、警告が消えたことを確認する。

## 例外（`#[expect]`の使用）
以下に該当する場合のみ許可する。（属性内の reason = "..." は必須）
- 外部ライブラリの制約で回避できない
- パフォーマンス上の理由で意図的に残す
- マクロ生成コードなど修正が困難
