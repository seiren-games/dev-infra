# dev-infra

複数のプロジェクトで開発環境や開発ルールを揃えるための共通設定集です。現在は Rust 向けの設定を提供しています。

- 開発ツールとコード整形・品質チェック
- GitHub Actions によるテストと依存関係の脆弱性チェック
- VS Code の開発設定
- AI コーディング支援用のルール

導入先のプロジェクトでは、Nix を使った開発環境の設定が必要です。環境の自動読み込みには direnv と nix-direnv を使用します。

導入済みプロジェクトの共通設定を更新するには、Linux（WSL を含む）で、プロジェクト直下の `sync.py` を実行します。Python 3、Nix、インターネット接続が必要です。

```sh
python3 sync.py
```

利用側で変更したファイルが競合すると、そのファイルは上書きされません。表示された内容を確認・調整してから再実行してください。

clone ごとに一度だけ、リポジトリ直下で Git hook を有効化してください。コミット・プッシュ時のチェックに必要です。

```sh
git config --local core.hooksPath .githooks
```
